# Apollo Solutions website

Public website assets for [Apollo Solutions](https://sobraniex.github.io/apollo-solutions/), including the [Apollo TUI product presentation](https://sobraniex.github.io/apollo-solutions/apollo-tui/).

GitHub Pages publishes the `main` branch from the repository root. The site lives under `apollo-solutions/` to preserve its existing URL.

The editable website source stays in the private `Sobraniex/apollo-solutions` repository. Its `scripts/export-pages.py` exports the tracked public website assets here; developer notes, scripts, and private history are excluded.
