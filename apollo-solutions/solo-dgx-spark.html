What's included

From model choice to a running service.

Before the session, we check whether your chosen model fits a single Spark. The scope is one model on one machine; the choice is confirmed against available memory, storage, and your intended use.

01

Review and prepare

We review the hardware, access, and requirements of the selected public recipe. We agree on remote access, typically SSH that you provide to your machine.

02

Install and configure

On your Spark, we install the needed components, model, and serving stack. We set model and server parameters such as quantization, context, and startup to suit its capacity.

03

Test and hand off

We start the service and send a test request through its API. We record the configuration, how to start and stop it, and the important limits.

How it works

One remote session. A clear handoff.

  1. Before the sessionWe confirm the model, hardware, free storage, and access. Remote work requires a working Spark and network connection.
  2. During the sessionWe install on your machine, start the service, and test it together. We adjust settings to the hardware's actual limits.
  3. After the sessionYou receive a handoff document with configuration and operating notes. For the next seven days, you can ask about this install or report a startup issue.

Frequently asked questions

Details before the install.

What exactly do I get?

One compatible open model installed and tested on one DGX Spark. You receive a handoff document with the settings, start and stop steps, and seven days of follow-up for that installation.

How does the remote installation work?

You provide temporary remote access to your Spark, typically over SSH. Installation and testing happen on your machine during the agreed session. We confirm access and network requirements beforehand.

Which model can you install?

We select one public recipe suitable for a single DGX Spark and confirm its fit before the session. Apollo's own repositories and documentation are still pending.

What happens after the session?

We send the handoff document and answer questions about this installation for seven days. Additional models, app integrations, and ongoing maintenance are outside this package.
