A little more context

Good questions.

What is Apollo TUI?

A terminal interface for AI-assisted software development. It combines a conversation with project tools, saved sessions, agents, and a sidebar for context, tasks, services, and changes.

Is this Apollo 1 or Apollo Agent?

Apollo TUI is the terminal product you can download here. Apollo 1 is our language-model project, and Apollo Agent is a separate agent project. Those two are still in development; Apollo TUI works with a provider and model you configure today.

Where is my code processed?

That depends on your selected provider and endpoint. Prompts and relevant project context are sent to the model you configure. Choose and review that configuration according to your project's data requirements.

Can it change files and run commands?

Yes. The agent can use project tools under your configured permission rules. Keep an eye on command output and diffs, and verify changes with your normal review and test workflow.

Which platforms are available?

The first packaged and checked release is macOS on Apple silicon. The repository includes native build targets for other platforms, but their packaged availability and checks will be listed in future release notes.
